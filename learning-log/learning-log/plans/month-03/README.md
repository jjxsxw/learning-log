# 第 3 个月：Agent（2026.12.21 – 2027.1.17）

## 本月目标

掌握大模型应用开发的主流技术栈，做出一个用 LangGraph 搭建、接入自写 MCP server、有评测数据的 agent 项目。

## 里程碑

- [ ] Agent 部署成服务，能通过接口调用

## 项目选题建议

选一个真实、自己会用的场景，比如：

- 技术文档研究助手：读 ESP-IDF 或 FreeRTOS 文档回答问题，并能查资料、写总结
- 代码仓库问答助手：针对某个开源项目回答"这个功能在哪实现"之类的问题

- 早上 30 分钟：刷 1 道算法题（周末 2 道）
