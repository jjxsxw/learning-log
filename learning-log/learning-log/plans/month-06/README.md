# 第 6 个月：求职冲刺（2027.3.15 – 4.25）

## 本月目标

写好三版简历，系统复习基础课和各方向面试题，准备好项目讲稿，开始投递并在面试中持续补短板。本月为 6 周。

## 里程碑

- [ ] 三版简历定稿（Agent / 端侧部署 / 嵌入式）
- [ ] 每个项目都能讲 5 分钟，并经得起追问
- [ ] 完成至少 2 次模拟面试
- [ ] 开始投递

## 每日固定动作

- 早上 30 分钟：刷 1 道算法题（周末 2 道），本月以复习错题为主
- 每晚 15 分钟：写当天记录到 `daily/`，提交到 GitHub
