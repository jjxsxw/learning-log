# 第 2 个月：嵌入式（2026.11.23 – 12.20）

## 本月目标

掌握 STM32 通信外设和 FreeRTOS，用 ESP32-S3 做出一个能联网的设备，并开始接触开源 RTOS 社区。

## 里程碑

- [ ] 能讲清 FreeRTOS 的任务调度、队列、信号量、互斥锁、优先级反转
- [ ] ESP32 设备能联网上报传感器数据，并响应远程指令
- [ ] 在 RT-Thread 或 Zephyr 中找到一个准备认领的入门 issue

## 每日固定动作

- 早上 30 分钟：刷 1 道算法题（周末 2 道）
- 每晚 15 分钟：写当天记录到 `daily/`，提交到 GitHub
