# 字母异位词分组：C++ 学习笔记

## 题目要做什么

把由相同字母、相同出现次数构成的单词放进同一组。例如：

```text
输入： ["eat", "tea", "tan", "ate", "nat", "bat"]
分组： ["eat", "tea", "ate"], ["tan", "nat"], ["bat"]
```

只看单词长度和“有哪些字母”不够：`"aab"` 与 `"abb"` 长度相同，也都有 `a`、`b`，但各字母的出现次数不同。

## 核心思路：给同组单词造同一个键

把单词的字母排序：

```text
"eat" → "aet"
"tea" → "aet"
"ate" → "aet"
```

排序后的字符串相同，原单词就属于同一组。用哈希表保存：

```text
排序后的字符串 → 一组原单词
"aet" → ["eat", "tea", "ate"]
"ant" → ["tan", "nat"]
```

## 完整代码

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;

        for (const string& word : strs) {
            string key = word;
            sort(key.begin(), key.end());
            groups[key].push_back(word);
        }

        vector<vector<string>> ans;
        for (const auto& entry : groups) {
            ans.push_back(entry.second);
        }

        return ans;
    }
};
```

## 逐行理解关键语法

### 1. 哈希表的类型

```cpp
unordered_map<string, vector<string>> groups;
```

- `unordered_map<键的类型, 值的类型>` 是哈希表。
- 键是 `string`，例如 `"aet"`。
- 值是 `vector<string>`，即一组字符串，例如 `{"eat", "tea"}`。
- `vector` 可以先理解成长度可变的数组。

### 2. 遍历输入

```cpp
for (const string& word : strs)
```

`strs` 是函数参数 `vector<string>& strs`，保存题目传入的所有单词。冒号可以读成“从 `strs` 中依次取出”；`word` 是在这句 `for` 里定义的变量，每轮代表当前单词。

三种常见写法：

| 写法                 | 是否复制元素 | 是否能修改容器里的原元素 |
| -------------------- | ------------ | ------------------------ |
| `string word`        | 是           | 否                       |
| `string& word`       | 否           | 是                       |
| `const string& word` | 否           | 否                       |

这里只读取原单词，因此用 `const string&`。

### 3. 复制并排序

```cpp
string key = word;
sort(key.begin(), key.end());
```

`key` 是 `word` 的独立副本。排序 `key` 后，原单词 `word` 不变。例如 `word` 仍是 `"tea"`，`key` 变成 `"aet"`。

`begin()` 和 `end()` 是函数，必须带括号；`sort(key.begin, key.end)` 是错误写法。

### 4. 找到组并加入原单词

```cpp
groups[key].push_back(word);
```

分成两步理解：

1. `groups[key]`：用键 `key` 取出对应的 `vector<string>`。如果键不存在，`[]` 会自动创建一个空的 `vector<string>`。
2. `.push_back(word)`：把原单词放到这个数组末尾。

例如第一次处理 `"eat"`：

```text
groups["aet"] → 新建空数组 [] → 加入 "eat" → ["eat"]
```

再处理 `"tea"`：

```text
groups["aet"] → 找到已有的 ["eat"] → 加入 "tea" → ["eat", "tea"]
```

这里的 `[]` 是**按键取值**，不是按数字下标取元素。它与 `nums[0]` 外形相似，但 `groups["aet"]` 中的 `"aet"` 是哈希表的键。

### 5. 取出所有组

```cpp
for (const auto& entry : groups) {
    ans.push_back(entry.second);
}
```

`entry` 在 `for` 语句中定义，每轮是哈希表里的一个键值对。`auto` 让编译器推断它的类型；`const &` 表示只读取且不复制。

- `entry.first`：键，例如 `"aet"`。
- `entry.second`：值，例如 `{"eat", "tea", "ate"}`。

答案只需要各组原单词，所以把每个 `entry.second` 加入 `ans`。`ans` 的类型是 `vector<vector<string>>`，可以理解为“装着多个单词组的数组”。

## 这次写代码时的易错点

1. `sort` 的参数应写成 `key.begin()`、`key.end()`，不能漏掉 `()`。
2. `key` 定义在第一个 `for` 的 `{}` 内，出了这个范围就不能继续使用。
3. 哈希表里可能有多个组，不能只写一次 `ans.push_back(groups[key])`；要遍历整个 `groups`。
4. 函数返回类型是 `vector<vector<string>>`，最后要 `return ans;`。
5. 范围 `for` 后不要误加分号：`for (...) ;` 会产生空循环。

## 复杂度与复习提示

设有 `n` 个单词，每个单词的最长长度为 `k`。对每个单词排序需要 `O(k log k)`，总时间约为 **`O(n × k log k)`**；哈希表及分组占用额外空间约 **`O(n × k)`**。

# 最长连续序列：C++ 学习笔记

## 题目要做什么

给定一个未排序的整数数组，找出数字连续的最长序列的长度。数字在原数组中不必相邻。

```text
nums = [100, 4, 200, 1, 3, 2]
最长连续序列：1, 2, 3, 4
答案：4
```

题目要求时间复杂度为 `O(n)`。排序后扫描容易想到，但排序需要 `O(n log n)`；要达到题目要求，可以使用哈希集合。

## 为什么用 `unordered_set`

这题只需要判断“某个整数是否存在”，不用保存它的下标或其他信息，所以用 `unordered_set<int>`。集合还会自动去重：`[1, 2, 2, 3]` 放入集合后只剩 `{1, 2, 3}`，连续序列长度是 3。

```cpp
unordered_set<int> seen;

for (int x : nums) {
    seen.insert(x);
}
```

`insert(x)` 把 `x` 放进集合。判断是否存在：

```cpp
seen.find(x) != seen.end()  // 找到了 x
seen.find(x) == seen.end()  // 没找到 x
```

`find(x)` 返回一个指向元素的迭代器；没找到时返回 `seen.end()`。`end()` 是末尾之后的特殊位置，不是最后一个元素。

集合还有更短的判断方式：`seen.count(x) == 1` 表示存在，`seen.count(x) == 0` 表示不存在。

## 核心思路：只从起点向后数

对于集合里的数 `c`：

1. 如果 `c - 1` **存在**，`c` 不是这段连续序列的起点，跳过。
2. 如果 `c - 1` **不存在**，`c` 是起点；接着查找 `c + 1`、`c + 2`……，直到下一个数不存在。
3. 记录这段长度，并更新最长长度。

例如集合 `{1, 2, 3, 100}`：

| 当前数 | 前一个数是否存在 | 操作                        |
| ------ | ---------------- | --------------------------- |
| 1      | 0 不存在         | 从 1 开始，数到 3，长度为 3 |
| 2      | 1 存在           | 跳过，不重复计数            |
| 3      | 2 存在           | 跳过，不重复计数            |
| 100    | 99 不存在        | 从 100 开始，长度为 1       |

集合的遍历顺序不固定；表格只是为了说明逻辑。建立集合后遍历 `seen`，而不是再次遍历原数组，可以避免重复数字导致同一段序列被反复统计。

## 完整代码

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> seen;

        for (int x : nums) {
            seen.insert(x);
        }

        int ans = 0;

        for (int c : seen) {
            if (seen.find(c - 1) == seen.end()) {
                int current = c;
                int length = 1;

                while (seen.find(current + 1) != seen.end()) {
                    current++;
                    length++;
                }

                ans = max(ans, length);
            }
        }

        return ans;
    }
};
```

## 三个变量分别做什么

- `current`：当前数到哪里了；找到下一个连续数时加一。
- `length`：当前这段连续序列的长度；每发现一个下一个数就加一，遇到新起点时重新设为 1。
- `ans`：到目前为止找到的最长长度；在外层循环之前设为 0，每数完一段后执行 `ans = max(ans, length)`。

例如已经数出长度 3 的序列，`ans = 3`。后来数出长度 5，`ans` 更新为 5；再数出长度 2，`ans` 仍是 5。

## 这次写代码时的易错点

| 写法或问题               | 正确做法                 | 原因                                      |
| ------------------------ | ------------------------ | ----------------------------------------- |
| `for (int c : x)`        | `for (int c : seen)`     | `x` 是单个整数；`seen` 才是要遍历的集合。 |
| `length = 1`，未声明变量 | `int length = 1`         | 首次使用局部变量时需要声明类型。          |
| 用 `if` 查下一个数       | 用 `while`               | 需要不断查找，直到连续序列结束。          |
| `unordered_set<int> ans` | `int ans = 0`            | 答案是“最长长度”，类型为整数。            |
| `max(length)`            | `ans = max(ans, length)` | `max` 比较两个值，结果要存回 `ans`。      |
| 数完后没有返回           | `return ans`             | 函数返回类型是 `int`。                    |

## 复杂度

设不同数字的个数为 `n`。建集合和查找的平均时间为 `O(n)`：每段连续序列只从起点向后数一次。额外空间为 `O(n)`。
