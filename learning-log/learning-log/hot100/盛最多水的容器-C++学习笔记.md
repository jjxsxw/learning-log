# 11. 盛最多水的容器：C++ 学习笔记

[题目链接](https://leetcode.cn/problems/container-with-most-water/)

## 一、先读懂题目

数组 `height` 的**下标**表示竖线的横向位置，`height[i]` 表示这条竖线的高度。任选下标 `i`、`j`（`i < j`）两条线作为容器两侧：

```text
宽度 = j - i
水的高度 = min(height[i], height[j])
面积 = (j - i) × min(height[i], height[j])
```

水的高度由较短的那条线限制。题目要找所有选法中的**最大面积**。

例如 `height = [1, 8, 6]`，选下标 `1` 和 `2` 时，宽度是 `1`，水的高度是 `min(8, 6) = 6`，面积是 `6`。

## 二、方法一：双重遍历

枚举每一对线，计算面积，更新最大值。这是最直观、容易验证正确性的解法。

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int ans = 0;
        int n = height.size();

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int area = (j - i) * min(height[i], height[j]);
                ans = max(ans, area);
            }
        }

        return ans;
    }
};
```

- 时间复杂度：`O(n²)`，因为检查了所有线对。
- 额外空间：`O(1)`。

## 三、方法二：左右双指针

一开始选最左和最右的两条线。每轮计算面积并更新答案，然后**移动较短的那一边**，直到两个指针相遇。

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0;
        int right = height.size() - 1;
        int ans = 0;

        while (left < right) {
            int area = (right - left) *
                       min(height[left], height[right]);
            ans = max(ans, area);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return ans;
    }
};
```

- 时间复杂度：`O(n)`，每轮至少移动一个指针。
- 额外空间：`O(1)`。

### 为什么移动短边

假设左线更短。保持左线不动、把右指针向左移动，**宽度变小**，水的高度仍不可能超过左线的高度，所以面积不可能比当前更大。原左线与内部任何右线的组合，都不必再检查；可以安全地移动左指针。右线更短时同理。

注意：移动短边后，**下一轮的面积不一定变大**。算法保证的是不会漏掉最大值，而不是每一步都进步。

### 两边一样高时怎么办

可以移动任意一边。移动左边和移动右边后，下一轮面积可能不同，但放弃哪一边都安全：保留这条高度为 `h` 的线、换成内部另一条线时，宽度会变小，水的高度不会超过 `h`，因此面积不会超过当前值。

上面的代码把“相等”归入 `else`，选择移动右边。指针相遇时，`while (left < right)` 结束，因为容器需要两条不同的线。

## 四、这题用到的 C++ 语法

```cpp
min(a, b)  // 返回较小值
max(a, b)  // 返回较大值
```

取较小值也可以用三目运算符：

```cpp
a < b ? a : b
```

意思是“如果 `a < b`，结果是 `a`；否则结果是 `b`”。本题写 `min(height[left], height[right])` 更直观。

## 五、面试手撕时怎么说

可以按“题意与公式 → 朴素解法 → 优化理由 → 代码 → 验证”的顺序表达：

> “我先确认一下：数组下标是线的位置，数组值是线的高度。选两条线时，容器宽度是下标差，水位由较短的线决定，所以面积是 `(j - i) * min(height[i], height[j])`。”

> “最直接的方法是枚举所有 `i < j`，计算面积并更新最大值，时间复杂度是 `O(n²)`，额外空间是 `O(1)`。”

> “可以优化为双指针。先把指针放在两端，每轮计算面积后移动短边。因为移动指针一定使宽度缩小；如果短边不变，水位不可能提高，所以那些组合不可能超过当前面积，可以排除。”

> “如果两边一样高，移动任意一边即可。两个指针相遇时结束。这样时间复杂度是 `O(n)`，额外空间是 `O(1)`。我会用题目示例走几轮，检查面积计算和指针移动。”

面试时先把双重遍历讲清楚，再说明为什么能从 `O(n²)` 优化到 `O(n)`。最重要的是解释**为什么移动短边不会漏解**，而不只是背出代码。
